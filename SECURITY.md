# Security Policy

## Supported versions

This is a community-maintained **beta** project. Security fixes, if available, are generally targeted at the latest published code. No formal security support or response-time guarantee is provided.

## Reporting a vulnerability

**Please do not disclose exploitable security issues in a public GitHub issue.**

If the repository has **GitHub private vulnerability reporting** enabled, use **Security → Report a vulnerability** on the repository page. If that option is unavailable, contact the maintainer through an existing private channel before publishing technical details. Do not post credentials or exploit details publicly.

Please include the affected version/commit, an impact summary, reproduction steps, and a suggested mitigation if known. Avoid testing on systems you do not own or have permission to assess.

## Scope and precautions

This project may interact with low-level hardware interfaces, services, and local administration tools. Protect any web interfaces, configuration files, and credentials according to your environment. Do not expose administrative interfaces directly to the internet.

The software is provided under the terms of the repository's GPL-3.0 license, without a warranty or guarantee of security support.
